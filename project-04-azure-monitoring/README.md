# Azure Project 04 - Monitoring & Logging

## Overview

This project introduces Azure monitoring and logging services using Terraform.

Resources deployed include:

- Azure Resource Group
- Azure Log Analytics Workspace
- Azure Monitor Action Group

- Azure Monitoring
- Centralized Logging
- Resource Organization
- Cloud Operations Fundamentals

## Technologies Used

- Terraform
- Microsoft Azure
- Azure Monitor
- Log Analytics Workspace
